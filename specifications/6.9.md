# SERVICE ABSTRACTION

Every external provider must be wrapped behind internal services.

Example

Instead of

stripe.checkout.sessions.create()

Create

BillingService.createCheckout()

Instead of

resend.emails.send()

Create

EmailService.send()

Instead of

Sentry.captureException()

Create

MonitoringService.capture()

Never allow business logic to directly depend on third-party SDKs.
