# OBJECTIVE

Authentication must feel effortless.

The user should be able to create an account and start building their business in less than 30 seconds.

The authentication experience must communicate:

• Trust
• Simplicity
• Premium quality
• Security

No friction.

No unnecessary fields.

---

# AUTHENTICATION METHODS

Urivo supports two authentication methods.

## 1.

Continue with Google

(Primary recommendation)

One-click account creation.

OAuth handled through Supabase Auth.

Automatically create the user profile on first login.

---

## 2.

Email & Password

User enters:

• Email Address
• Password

Requirements:

Minimum 8 characters

At least:

• 1 uppercase letter
• 1 lowercase letter
• 1 number

Optional password strength indicator.
