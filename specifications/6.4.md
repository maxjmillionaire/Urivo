SECTION 35 — CI/CD PIPELINE

Every push to the repository must trigger an automated pipeline.

Pipeline order:

1. Install dependencies
2. Lint source code
3. Type checking
4. Unit tests
5. Integration tests
6. Build application
7. Security audit
8. Container build
9. Deploy staging
10. Smoke tests
11. Manual approval
12. Production deployment

Deployment must stop immediately if any step fails.

⸻

SECTION 36 — DOCKER STANDARD

Provide production-ready Docker configuration.

Requirements:

* Multi-stage build
* Small production image
* Non-root user
* Environment variables only
* Healthcheck instruction
* Graceful shutdown support

Never embed secrets inside images.

⸻

SECTION 37 — ENVIRONMENT STRATEGY

Maintain separate environments:

Development

Staging

Production

Each environment must have:

* isolated database
* isolated Redis
* isolated Stripe configuration
* isolated API keys
* isolated analytics

Production credentials must never be used outside Production.
