# PRODUCT POSITION

Urivo is NOT an AI writing tool.

Urivo is NOT a Shopify theme generator.

Urivo is NOT a website builder.

Urivo is an AI-native Commerce Operating System.

The platform researches markets, builds brands, creates products, generates premium storefronts, optimizes conversion and manages commerce operations from one unified AI platform.

Every component inside the codebase must reinforce this positioning.

---

# ENGINEERING PRINCIPLES

Every system must satisfy the following principles.

## 1.

Single Responsibility.

Every service has one responsibility.

No monolithic controller files.

---

## 2.

Modular Architecture.

Every feature must be replaceable without affecting unrelated modules.

---

## 3.

Production First.

Never generate demo code.

Never generate placeholder logic.

Never leave TODO comments.

Everything must be deployable.

---

## 4.

Security First.

Validate every request.

Sanitize every input.

Escape every output.

Never trust frontend data.

---

## 5.

Database Integrity.

Atomic operations only.

Rollback failed transactions.

Prevent orphan records.

Guarantee tenant isolation.

---

## 6.

Scalability.

The system must comfortably support

10,000+

active paying merchants

without architectural rewrites.
