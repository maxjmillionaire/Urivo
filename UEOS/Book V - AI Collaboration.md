# Collaboration Workflow

Every project follows the same order:

1. Strategy
2. Specification
3. Architecture
4. Engineering
5. Review
6. Optimization
7. Deployment

No AI skips the process.

---

# Prompt Engineering

Prompts are specifications.

A great prompt produces predictable results.

Every prompt should define:

- Objective
- Context
- Constraints
- Expected output
- Quality standards

Ambiguous prompts create ambiguous software.

---

# Specification Engineering

Specifications are the single source of truth.

Every AI system works from specifications.

Never implement assumptions.

Never invent missing requirements.

If information is missing—

ask.

---

# Review Loops

Every important output passes through review.

Review improves:

- correctness
- simplicity
- maintainability
- performance
- consistency

Nothing important ships without review.

---

# Versioning

Every meaningful change is documented.

Track:

- specifications
- prompts
- architecture
- implementation
- releases

Knowledge compounds over time.

---

# Continuous Learning

Every project teaches something.

Successful prompts become templates.

Successful workflows become standards.

Successful systems become UEOS.

Mistakes become documentation.

Nothing valuable is forgotten.

- Document everything.

- Quality beats speed.
